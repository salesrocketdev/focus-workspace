# Provider artwork — prototype only

These SVG files are third-party brand representations, not original project marks. They are not relicensed under Focus Workspace's MIT license. Source files are copied unmodified from the following public collections for the V4 visual prototype:
- `google-calendar.svg`: https://github.com/gilbarbara/logos/blob/main/logos/google-calendar-2020.svg
- `gmail.svg`: https://github.com/gilbarbara/logos/blob/main/logos/google-gmail-2020.svg
- `outlook.svg`: https://github.com/o-ocn/icons/blob/main/icons/outlook.svg
- `spotify.svg`: https://github.com/gilbarbara/logos/blob/main/logos/spotify-icon.svg
- `google-meet.svg`: https://github.com/gilbarbara/logos/blob/main/logos/google-meet-2020.svg
- `teams.svg`: https://github.com/gilbarbara/logos/blob/main/logos/microsoft-teams.svg

The Google Calendar/Gmail/Meet 2020 versions and Outlook classic icon are selected for fidelity to the approved V4 concept; not necessarily current product artwork. Spotify and Teams are collection versions. No claim of affiliation, approval or functional connection. The app does not integrate Gmail or video calling; Meet and Teams are planned only as event links.

Before releasing production builds, verify usage rights, approved asset versions and brand attribution/clear space. If permission is not available, replace the relevant SVG with a generic Lucide icon and plain text provider name. The source collection license does not grant trademark rights.

- Microsoft: https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks

Keep assets local; no third-party image requests at runtime. Do not recolor brand marks or use them in the Focus Workspace logo.
