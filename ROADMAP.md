# Roadmap

Delivery status lives in GitHub Issues; phases below are release gates, not dates or completed features.

| Phase | Gate |
|---|---|
| M0 Product & design foundation | Review product/visual/technical docs, version approved concept, triage issues, board configured |
| M1 Application foundation | Monorepo, app shell, design tokens, locales, local storage, early native spike, CI |
| M2 Dashboard engine | Add/remove/configure/reorder/resize, responsive variants, persistence |
| M3 Focus & activities | Timer, activities, tasks, history, daily goal, native/web recovery |
| M4 Connected calendar | Google + Outlook read-only sync, consolidated agenda, meeting links, free windows |
| M5 Personal productivity | Reading tracker, richer insights, ambient/Spotify, compact/immersive polish |
| M6 Cross-platform & sync | Android/iOS, optional backend sync and self-hosting |
| M7 Public release | Security/accessibility/provider policy review, license and release documentation |

M0–M4 first usable Windows/web target. A thin vertical slice (timer + one widget + local persistence) is recommended before building all widgets. Mobile spike early, packaging later. Release sequencing subject to review. No coding in M0.
