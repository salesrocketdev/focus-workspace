# Focus Workspace

Your time. Your space. Your rhythm.

An open-source, cross-platform personal focus workspace with customizable widgets, Pomodoro, calendar integrations, task management, reading tracking, music and productivity insights.

## Product
Focus Workspace combines attention management and daily planning for work, study, reading and personal activities. The dashboard is user-configurable; a session can start without an account, task or external provider.

## Status
Planning / pre-implementation. Windows and web are the first release targets; Android and iOS are planned, with platform validation early. No application or integration is implemented yet. The repository is private during planning; public release is a separate decision by the maintainer. MIT license.
